# Housing System

This repository contains a standalone housing system for FiveM servers. It provides a robust and feature-rich house ownership system, enhancing the role-playing experience and providing players with a sense of property ownership.

## Installation

1. Drag and drop the script into your resource file and ensure it.
2. Add your housing postals into the config file.

## Usage

The following commands are available for interacting with the housing system:
- `/buyhouse [Postal] - This is for buying a house solo`
- `/buyhouse [postal] [Player2 - CFXName] - This is for buying a housing with someone`
- `/sellhouse [postal]- This is for selling a house solo`
- `/sellhouse [postal] [Player2 - CFXName] - This is for selling the house with someone`
- `/listhouses - This is to see all the houses from your config file and it will show who has bought a bought and what postal`
- `/listhousekeys [postal] [Your CFXName] - This shows the list of house keys.`
